## 아트 방향

- 아트 필러: 따뜻함 · 그림책 · 힐링 · 한국적 일상 · 부드러운 풍자.
- 금지: 자극색, 냉소, 대시보드형 화면, 카운트다운 도박 연출, 실존 브랜드·인물 연상 디자인.
- 컬러: 베이스 크림 `#FBF3E7`, 코럴 `#F28C79`, 세이지 `#A7C4A0`, 소프트블루 `#7FA9D9`, 앰버 `#E8B54D`, 웜핑크 `#F4B8C1`, 텍스트 웜다크브라운 `#4A4038`. 의미색만 기능색(성적 블루, 정서 코럴, 스트레스 앰버, 유대감 웜핑크). 다크모드 대응.

## 시각 문법

- 2D 그림책 + 플랫, 뭉툭한 라운드, 2.5~4등신(유아 동글 → 고등 길쭉).
- 표정 과장이 반응 컷의 생명. 표정 시트: 기쁨·신남·시무룩·지침·뿌듯·반항·집중.
- 모션·VFX 언어: 긍정 = 반짝이·하트·바운스·델타 팝업 부상 / 스트레스 = 시무룩·땀방울·앰버 펄스(절제) / 전환 = 짧은 페이드·성장 모프 / 전환기 = 따뜻한 라이팅의 대화 컷(감정 클라이맥스).

## 캐릭터와 세계

- 성장 단계 실루엣 변화가 핵심 시각 장치: 유아 → 초등(책가방) → 중등(교복·사춘기) → 고등(키·다크서클).
- 모듈형 캐릭터: 나이 단계별 공용(중성적) 베이스 바디 1종 + 교체형 헤어·의상·얼굴 파츠. 아들/딸/중성은 파츠 프리셋일 뿐 전용 아트 2벌을 그리지 않는다. 코스메틱 가챠·꾸미기가 성별 표현을 겸용해 아트 비용과 수익화 시너지를 동시에 잡는다.
- 부모 = 플레이어 시점(화면 밖). 유대감 이벤트에서만 손·뒷모습·실루엣으로 암시해 투영을 극대화한다.
- 세계 네이밍(확정): 한울대(최상위 명문대), 배치동(학원가), 기관 14슬롯·강사 캐릭터 6종(나수리·도지문·오단어·백실험·한설득·금나침)은 기획 원본 6-A-2 확정표를 따른다. 전 명칭 가상, 게임 내·스토어에 허구 면책 고지 삽입.

## UI 아트 경계

- 텍스트·게이지·버튼·리스트 등 늘어나는 UI는 Godot에서 렌더링한다.
- 생성 이미지는 캐릭터·배경·아이콘·엔딩 CG·장식 요소에만 사용한다.
- 대표 플레이 화면 브리프: 따뜻한 아침 햇살이 창으로 드는 아늑한 집(계절 소품), 아이가 중앙에서 카메라를 향해 반응 + 미세 idle 애니, 상단 얇은 정보바, 하단 단일 CTA, 스탯은 접히는 얇은 바.

## 에셋 매니페스트

Vertical Slice 첫 배치:

| 분류 | 수량 |
| --- | --- |
| 캐릭터 베이스(유아·초등 2단계) | 2종 + 표정 6~8 + 파츠 프리셋 3(아들/딸/중성) |
| 배경 | 우리 집 1(계절 variant) + 활동 배경 2~3(놀이터·학원·시골) |
| 활동 아이콘 | 대표 8종 |
| UI 키트 | 카드·버튼·게이지·팝업의 상태 variant 일괄 |
| 엔딩 CG | 대표 1종 |
| 로고·앱 아이콘 | 티저 1종 |

- 본편 물량: 캐릭터 4단계 전체 + 엔딩 CG 12종(전용) + 공용 엔딩 프레임, 코스메틱 스킨은 시즌 단위 생산.
- 상태 variant(눌림·비활성·잠금)는 매니페스트에 포함해 생성 단계에서 함께 뽑는다.

## VFX 언어

- 델타 팝업: 스탯 색상으로 부상 후 소멸, 동시 다발 시 스태거.
- 긍정 파티클은 부드러운 원형 입자·하트, 스트레스는 펄스 1회(연타 금지).
- 전환기·엔딩은 라이팅 변화 중심(파티클 과용 금지)으로 감정을 만든다.

## 생성과 라이선스

- 이미지 에셋은 game-asset-pipeline으로 style anchor 고정 후 batch/QA 순서로만 생성한다. 계획 단계에서 유료 생성 API를 호출하지 않는다.
- 생성물·외부 자산마다 출처, 모델·도구, 프롬프트·참조, 라이선스, 수정 이력, 마켓 사용 가능성을 추적 표로 남긴다.
- 폰트는 임베딩 라이선스 확인 후 채택한다. 채택된 가상명은 에셋·카피 제작 전 실존 상호 간단 검색을 거친다.
