## 기능 QA

- 가챠: 표기 확률(3.0/17.0/80.0)·천장 40회·마일리지 전환을 시드 고정 시뮬 10만 회 로그로 검증. 유상·무상 풀 동일성 확인.
- 저장: 턴 자동 저장 왕복(AC-006), 스키마 마이그레이션 구버전 픽스처 회귀, 클라우드 병합·충돌 시나리오.
- IAP: sandbox 구매·복원·pending·중복 영수증, Cloud Functions 검증 실패 폴백.
- 광고: 캡(세션 8·일 18)·최소 간격·미노출 구간(초반 세션·엔딩) 강제 확인.
- 전환기·유혹: 확률 곡선 경계값, 광고 부스트 1회 한정, 의존 게이지 임계 이벤트.

## 개인정보 정책과 연령등급

- 등급 전략(확정): 실제 등급 15세 목표 + 성인 타깃 마케팅. 청소년이용불가는 자체등급분류 대상이 아니므로 15세 초과 판정은 출시 경로 자체를 바꾼다 — 수위 관리가 QA 항목.
- 약물·편법 묘사 QA: 투약 행위·효과의 구체 연출 없음, 실존 약품명 없음, 미화 없음, 부작용·적발 명확 — 콘텐츠 리뷰 체크리스트로 전 이벤트 검수. 유혹 이벤트 노출 빈도가 Apple 설문 기준을 넘지 않도록 빈도 상한 관리.
- IARC·Apple 설문: 정직 응답, 응답 내용을 저장소에 버전 관리. 필요 시 게임위 등급분류 사전 상담.
- 개인정보: 익명 인증·최소 수집, 처리방침 게시, 계정·데이터 삭제 기능. 아동 대상 아님(성인 마케팅) 포지셔닝 유지.

## 스토어와 정책

출시 전 정책 게이트 체크리스트(기획 원본 14장 기준):

1. 사행성 트리거 없음 — 실제 재화 환전·베팅 없음, 보상은 게임 내 소비 전용.
2. IARC 설문안 확정 — 가챠·약물 소재 정직 기재.
3. 가챠 확률·천장 공개 UI 구현 — 구매 직전 화면·게임 내 상세·홈페이지 검색 가능 형태·한국어 광고물 표기.
4. 연령 포지셔닝 — 15세 등급 + 성인 마케팅 정합 확인.
5. 광고 SDK 정책 — 맞춤형 광고 동의·SDK 최신 정책 준수.
6. 가상 네이밍 전면 적용 + 허구 면책 고지 삽입.
7. 아동 묘사 수위 — 학대·착취 미화 없음, 아이콘·스크린샷 전연령 적합.
8. 개인정보 처리방침·최소 수집·계정 삭제.
9. 약물·편법 묘사 수위 — 가상명·미화 금지·부작용 명확.

- 출시 직전 재확인: 게임산업법 시행령 제19조의2 원문, 모바일 청소년이용불가 등급의 GCRB 이양 확정 여부, 문체부 해설서 개정 여부.
- 마케팅 금지어: "수험생 키우기"(타사 등록상표) 명칭 표기 금지.

## 출시 포지셔닝과 획득

- 포지셔닝: "어른들의 풍자 힐링 육성" — 한국 입시를 겪은 성인에게 "내가 부모라면"을 굴려보게 하는 게임. 명문대만이 답이 아니라는 메시지를 전면에.
- 스토어 카피 축: 부모 시점 + 힐링 + 다중 엔딩 수집. 스크린샷은 아이 반응 컷·성장 연출·엔딩 CG 중심(대시보드 컷 금지).
- 획득: 교육열 밈 채널(커뮤니티·쇼츠) 공유용 엔딩 결과 카드, 시즌 이벤트 재방문 훅. 성인 타깃 광고 집행(아동 채널 제외).

## 현지화와 고객지원

- 한국 단독·한국어 전용. 현지화 부담 없음, 교육 문화 고증 감수에 집중.
- 지원 채널: 스토어 리뷰 대응 + 인앱 문의 링크. 환불·구매 복원 FAQ, 확률 정보 페이지 상시 게시.

## 소프트론칭

- 방식: Google Play 비공개·공개 테스트 트랙으로 단계 확대(한국 시장 단독이므로 국가 분리 대신 트랙 분리).
- 판정 지표(2주 이상 관찰): D1 38% 이상, 첫 엔딩 도달률 35% 이상(가설), 크래시 프리 99.5% 이상, 보상형 자발 시청률, 온보딩 완료율.
- 판정 규칙: 지표 충족 시 확대, 미달 시 가설 수정 후 재측정, D1 25% 미만 반복 시 코어 페이싱 재설계(00 문서 중단 기준).

## 론칭 게이트

1. 정책 게이트 9항 전부 통과 + 등급 15세 확정.
2. 실기기 3티어 QA 통과(기능·성능·접근성).
3. 서명 빌드: Android AAB(target API 36, x64 Linux 러너) + iOS archive(Xcode 26, macOS 러너) 업로드 검증.
4. 마켓 메타데이터·스크린샷·확률 정보 페이지 준비, telemetry 대시보드 가동.
5. 소프트론칭 지표 게이트 통과.

## 롤백과 운영

- 단계 출시(Android staged rollout, iOS 단계 배포)로 시작. 크래시 프리 99.5% 미만 또는 저장 손실 리포트 발생 시 즉시 롤아웃 중지.
- 저장 손상 대응: 클라우드 백업 복원 절차와 고객 문의 처리 경로를 사전 문서화.
- Remote Config로 광고 캡·이벤트를 즉시 끌 수 있는 킬 스위치 유지. 확률·가격 변경은 공지 절차 필수.
- 라이브 위반 모니터링: 게임위 자체등급분류 사후관리·문체부 확률 표시 점검에 대응할 수 있게 설문 응답·확률 로그·공지 이력을 보관한다.
