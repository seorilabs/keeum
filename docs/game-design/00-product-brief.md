- 부차 사용자: 실제 학부모, 예비 부모, 입시를 갓 지난 대학생.
- 사용 맥락: 출퇴근·자투리 시간, 취침 전 한 학기 마무리. 1세션 3~7분, 한 판 완주 20~40분.
- 플랫폼: 모바일 세로 고정. 오프라인 우선 플레이(서버는 세이브 동기화·검증·분석 전용).

## 플레이어 판타지와 제품 기둥

판타지: "내가 부모라면 어떻게 키울까"를 안전하게, 유쾌하게, 여러 번 굴려보는 경험. 실제 육아는 되돌릴 수 없지만 게임은 회차로 다시 키울 수 있다.

1. 하나의 조작, 깊은 결과 — "이번 달 무엇을 시킬까" 단일 선택이 성적·정서·재력·유대감의 트레이드오프로 깊어진다.
2. 균형의 서사 — 성적만 밀면 아이가 무너지고, 균형을 지키면 느리지만 단단히 자란다. 메시지가 곧 메커니즘.
3. 따뜻한 다중 엔딩 — 명문대만 성공이 아니다. 예체능·창업·"평범하지만 행복"도 긍정 엔딩.
4. 광고 절제 UX — 경쟁작 1순위 불만(광고 폭탄)을 정면 회피. 보상형은 유저 주도 지점에만.

## 범위

- v1 출시 재고: 활동 20~30종, 이벤트 40~60개, 엔딩 40개(전용 CG 12개), 직업 도감은 라이브에서 100개 이상으로 확장.
- 의도적 제외: 실시간 멀티플레이·PvP 랭킹, 성능형 가챠(코스메틱 한정), 실존 대학·학원·강사 실명(전면 가상 네이밍), 별도 커리어 시뮬(직업은 엔딩 에필로그 텍스트·도감으로만), 실제 재화 환전.
- AppsInToss: phase 2 후보. Godot Web 성능과 AIT 광고·결제 지원 범위 확인 후 결정.

## 제작 제약과 팀
